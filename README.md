# Консольный аналог игры Arkanoid

Консольное приложение на C#
[Arkanoid](https://en.wikipedia.org/wiki/Arkanoid) с предметами (бонусами),
выпадающими из разрушенных кирпичей. Графический интерфейс не используется.

## Правила игры

- Поле 50×20 клеток, 40 кирпичей в 4 ряда. Верхние ряды дороже:
  40, 30, 20 и 10 очков за кирпич.
- У игрока 3 жизни. Мяч, упавший за нижнюю границу, отнимает жизнь
  и возвращается на ракетку.
- Победа — все кирпичи разрушены; поражение — жизни закончились.
- С вероятностью 40% из разрушенного кирпича выпадает предмет,
  который медленно падает вниз. Если поймать его ракеткой, применяется эффект:

## Предметы
E - Expand, Расширяет длину ракетки
S - Slow, Замедляет мяч
L - ExtraLife, Даёт дополнительную жизнь

Упущенный предмет пропадает за нижней границей поля.

## Управление

| Клавиша | Действие |
|---|---|
| `←` / `→` | Движение ракетки |
| `Space` / `Enter` | Запуск мяча с ракетки |
| `Esc` | Сохранить состояние в `save.json` и выйти |
| `Д` / `н` | Ответы на вопросы (продолжить игру, сыграть ещё раз) |

Мяч стартует закреплённым на ракетке и следует за ней до запуска.
При попадании мяча в ракетку угол отскока зависит от точки попадания.

## Сборка и запуск

```powershell
# сборка приложения
dotnet build Lab3.csproj

# запуск игры
dotnet run --project Lab3.csproj
```

Файл сохранения `save.json` создаётся в рабочей папке рядом с проектом.
Если при запуске найден файл сохранения, программа спрашивает, продолжить ли игру.

## Тесты

```powershell
# запуск тестов с выводом каждого теста и его результата
dotnet run --project Lab3.Tests\Lab3.Tests.csproj -- --output Detailed
```

Каждый тест выводится строкой «пройдено <имя теста>» (при падении — «сбой <имя теста>»
с причиной), в конце печатается сводка: всего / сбой / успешно. Все 37 тестов проходят.
